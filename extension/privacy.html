Evidence Clip Ledger

Privacy disclosure

Data handled

Only after the user clicks the extension, Evidence Clip Ledger reads the active tab title and URL. It also stores the fact, grade, strength, case name, and note entered by the user.

Purpose

This information is used only to provide the extension's single purpose: creating a user-directed source evidence ledger.

Storage and transfer

Records are stored in Chrome local extension storage on the user's device. The extension has no server and does not transmit, sell, share, or allow human access to extension data. Export occurs only when the user explicitly downloads a JSON or CSV file.

Advertising and analytics

The extension contains no advertising, analytics, telemetry, tracking, remote code, or background browsing.

User control

Users can delete individual records or all records from the archive. Removing the extension also removes its local extension storage according to Chrome behavior.

Limited Use disclosure

Use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Effective date: August 23, 2026
