# Evidence Clip Ledger 1.0.0

Manifest V3 Chrome extension source for a local, user-directed web evidence ledger.

## Local verification

1. Open `chrome://extensions`.
2. Enable Developer mode.
3. Choose **Load unpacked** and select the `extension` directory.
4. Open a web page and click the extension action.
5. Save a record, open Archive, then export JSON and CSV.

## Chrome Web Store path

Publishing requires an already registered Chrome Web Store developer account. The official registration page states that a one-time registration fee is mandatory. This project does not authorize or perform that payment.

After registration, upload the distribution ZIP, complete the Store Listing and Privacy tabs, add the supplied screenshots, and submit for review only under a scoped approval.
